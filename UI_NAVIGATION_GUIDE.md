# Category-Based UI Navigation

The application sidebar has been reorganized into collapsible groups to keep 20+ tools easy to navigate.

## Groups

- **Overview:** Dashboard, Resource Hub, Student Portal
- **AI Content Studio:** AI Resource Studio, PPT Studio
- **Personalized Learning:** Adaptive Notes, Flashcards
- **Academic Planning:** Question Paper Studio, Course Planner, Revision Planner, Coding Lab, Case Studies, Lesson Calendar
- **Assessment & Analytics:** Quiz Center, Analytics
- **Multimedia & Intelligence:** Voice Studio, Diagram Studio, Smart Search
- **Collaboration:** Collaboration, Department Hub
- **Administration:** Security Center (admin only)

## Smart deep-links

Sidebar items such as Adaptive Notes, Flashcards, Question Paper Studio and Voice Studio open the existing phase view and automatically focus the selected tool.

## Responsive behaviour

On desktop the sidebar remains sticky. On tablets and phones it becomes an animated drawer with an overlay, close button and Escape-key support.
