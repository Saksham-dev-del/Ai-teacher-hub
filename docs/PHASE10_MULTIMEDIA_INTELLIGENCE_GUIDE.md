# Phase 10 — Multimedia, Search and Platform Intelligence

Phase 10 adds AI voice scripts, browser narration, Gemini TTS WAV download, academic video scripts, SVG diagrams, internal similarity/originality risk analysis, AI safety review, semantic hybrid resource search and an offline-capable PWA shell.

## Important limitations
- Similarity/AI-writing scores are risk indicators, not proof of misconduct.
- Gemini TTS needs a valid API key and a TTS-capable model.
- Offline mode caches the app shell and recent local resource metadata; server-backed AI, sync and secure quiz actions need connectivity.
