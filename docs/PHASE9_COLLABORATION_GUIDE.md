# Phase 9 — Collaboration and Content Management

Phase 9 adds faculty workload metrics, departments, shared folders, comments, review workflows, version snapshots, restore, ratings and QR-based public sharing.

## Workflow
Draft → In Review → Approved / Rejected. Reviewers are assigned at department level. Approved resources automatically receive a **Final Approved Version** snapshot.

## Version labels
Version 1, Version 2, Reviewed Version and Final Approved Version are supported. Restoring an old version creates a new snapshot so history is never silently overwritten.
